# 三层任务池 · Three-Layer Task Pool

一个**纯本地、单文件**的三层任务池计划工具。无需安装、无需服务器、无需联网，双击 `index.html` 即可使用，所有数据保存在本机浏览器中，不上传任何网络。

界面为原子笔记风格的极简设计，采用**手风琴式三层布局**：战略总池（灰）→ 本周聚焦（琥珀）→ 今日动态（红）。**每次打开默认只展开「今日动态列表」**，其余两栏折叠为横向栏，点开才展开——打开页面即专注今日待办，不被积压任务分散注意力。

## ✨ 功能特性

- **手风琴式三层任务池**
  - **战略任务总池**（Strategic Backlog）：所有中长期任务与嵌套子任务的仓库；可直接勾选完成/取消完成，状态同步到各池
  - **本周聚焦池**（This Week's Focus Pool）：本周要推进的任务；被选入今日列表的任务会标注 `→ 今日` 箭头（表示已出库，但在周池中保留）；今日任务完成或退回后箭头消失
  - **今日动态列表**（Today's Dynamic List）：今天要执行的任务；完成后**划线保留**在列表中并计入「今日已完成」（只统计在今日列表中完成的条目，在其他池完成不计入），零点自动隐藏（也可随时手动隐藏）；未完成的任务零点自动**返回周池**（箭头随之取消，任务保留在周池，不会退回总池）
  - 每栏可随时点击栏头展开 / 折叠；**拖拽任务悬停在折叠栏上约半秒会自动展开**，跨池投放不中断
- **两级拖拽**（桌面与手机触屏均支持）
  - 拖**任务卡**左侧 `⠿` 手柄：跨池移动、池内排序
  - 拖**子任务**行的小手柄：在本卡子任务区内上下拖动 = 调整顺序；**拖到其他池 = 只把该子任务单独取出到那个池**（主任务原地不动），池内显示为 `主任务.编号` 条目，浮层同样显示「所属：主任务.编号」
- **子任务自动编号**：子任务按顺序显示 `1. 2. 3.`，拖拽排序后编号自动跟着变化
- **子任务出库条目**（池内显示为 `主任务.编号` 的独立条目）
  - 点击只编辑**该子任务本身**的内容，不会展开整个主任务
  - 勾选完成与主任务卡片内的子任务实时同步；在今日完成后同样自动归档并计入「今日已完成」
  - 拖回总池、点 ✕ 或弹窗内「收回总池」= 仅从各池移出，子任务仍保留在主任务内（出库但保留）
  - 主任务卡片内会给出库的子任务标注 `→ 今日 / → 本周` 小箭头，与任务箭头语义一致
- **任务管理**：标题、简短备注、嵌套子任务；支持新增 / 编辑（弹窗居中显示）/ 删除 / 勾选完成，子任务可直接在卡片上勾选或快速追加
- **截止日期**：编辑任务时可选填（系统日历选择器）；填好后卡片上显示倒计时徽标，**距离越近颜色越重**：白（一周以外）→ 蓝（4–7 天）→ 黄（1–3 天）→ 红（当天截止 / 已逾期）
- **每日重复任务**：编辑任务时勾选「每日重复」，卡片显示 `⟳ 每日` 徽标；零点结算时自动**重置完成状态（含全部子任务）并回到今日列表**，适合听力打卡、每日复习等习惯任务。只对零点时仍在今日列表的重复任务生效——当天被显式拖回周池的不会自动回来
- **级联完成**
  - 勾选主任务 → 全部子任务**自动一并完成**（包括已拖到周池 / 今日池的出库子任务，今日中的同步归档）
  - 子任务**全部完成**时 → 任务自动标记为整体完成（无需再手动打勾），并遵循今日完成自动归档
  - 在已完成的任务中**取消某个子任务** → 任务自动恢复为未完成；取消主任务则保留子任务的完成状态
- **数据本地持久化**：自动保存在浏览器 localStorage 中，关闭页面后数据不丢失；支持一键导出 / 导入 JSON 备份
- **多设备同步（可选）**：通过你 GitHub 账号下的**私密 Gist** 在 PC 与手机间同步数据；打开页面自动拉取、改动后自动推送（约 2.5 秒防抖），离线照常使用、联网自动补推；不配置则完全离线，行为与单机版一致
- **移动端适配**：手机上同样为手风琴布局，栏头与手柄都是合适的触控尺寸，输入框自动放大避免 iOS 聚焦缩放
- **键盘快捷键**：`/` 展开总池并聚焦搜索框；`1 / 2 / 3` 快速展开或折叠 战略总池 / 本周聚焦 / 今日动态（输入框内或弹窗打开时不触发）
- **零依赖**：整个项目只有一个 HTML 文件，不引用任何外部库、字体或网络资源，完全离线可用

## 🚀 如何运行

**双击项目目录下的 `index.html`**，用浏览器（推荐 Chrome / Edge）打开即可，无需任何安装步骤。

> 小技巧：可以把 `index.html` 固定到浏览器书签或桌面，下次一键打开。

**在手机上使用**（任选其一）：

1. 把 `index.html` 通过微信 / 网盘 / 数据线发送到手机，用手机浏览器打开该文件；
2. 或者临时在电脑上起一个本地服务，手机同一局域网访问（可选，非必需）：
   ```bash
   # 电脑上进入项目目录后执行（需已安装 Python）
   python -m http.server 8000
   # 手机浏览器访问 http://电脑IP:8000
   ```

## 📖 使用说明

| 操作 | 方式 |
| --- | --- |
| 展开 / 折叠某栏 | 点击该栏的横向栏头（栏头右侧实时显示数量统计） |
| 新增任务 | 展开目标池，在顶部输入框输入标题，按 **回车** 保存 |
| 编辑任务 | 点击任务卡片（或卡片右侧 ✎），弹窗居中弹出，可修改标题、备注、子任务 |
| 删除任务 | 卡片右侧 ✕（有二次确认），或编辑弹窗中的「删除任务」 |
| 跨池移动 | 按住卡片左侧 **⠿ 手柄** 拖到目标池（折叠栏悬停约半秒自动展开）；目标池高亮并显示插入位置 |
| 池内排序 | 同样拖拽 ⠿ 手柄，在同一个池内上下调整顺序 |
| 子任务排序 / 单独出库 | 按住子任务行左侧的小手柄：在本卡子任务区内拖动为排序（编号自动变化）；拖到其他池 = 只取出该子任务，池内显示为 `主任务.编号` 条目 |
| 出库条目（主任务.编号） | 点击 → 只编辑该子任务内容；勾选完成与主任务内同步；✕ 或「收回总池」= 移出各池但保留在主任务内；也可再拖到其他池或拖回原位置 |
| 完成任务 | 任意池中点击方框勾选（含总池）= 全部子任务一并完成；在今日完成后划线保留至零点（或手动隐藏），之后归档回周池 |
| 截止日期 | 编辑任务时用日历选择器选择（可选）；卡片显示「剩 N 天 / 今天截止 / 逾期 N 天」徽标，颜色白 → 蓝 → 黄 → 红 随临近加深 |
| 每日重复 | 编辑任务时勾选「每日重复」；零点自动重置完成状态并回到今日列表（当天被拖回周池的除外） |
| 键盘快捷键 | `/` 展开总池并聚焦搜索；`1` `2` `3` 展开 / 折叠对应池 |
| 隐藏今日已完成 | 今日池顶部「隐藏已完成 / 显示已完成」按钮随时切换；不点的话零点也会自动隐藏 |
| 子任务 | 点开卡片上的「▸ 子任务 n/n」直接勾选，末行输入框回车快速追加；子任务全部勾完时任务自动整体完成 |
| 搜索 / 过滤 | 总池内支持按标题、备注、子任务搜索，以及隐藏已完成 |
| 归档 | 周池中出现「归档已完成」按钮时，点击可把已完成任务收回总池 |
| 多设备同步 | 顶栏「同步」→ 粘贴 GitHub 细粒度令牌（只授 Gists 读写）→「连接云端」；每台设备各连一次即可 |

**箭头状态说明**

- 周池中任务带 `→ 今日`：该任务已进入今日列表（出库但保留在周池）
- 今日任务被**完成** → 箭头消失，任务在今日列表划线保留至零点（或手动隐藏）后归档回周池，总池中该任务显示已完成
- 今日任务**未完成跨过零点** → 自动返回周池，箭头消失，任务留在周池继续推进（周池中的任务不会自动退回总池）
- 今日任务被**拖回周池**（未完成返回）→ 箭头消失，任务留在周池继续推进
- 子任务同样适用：主任务卡片内子任务带 `→ 今日 / → 本周` 小箭头 = 该子任务已单独出库到对应池
- **子任务拖到今日池只在今日显示**，不会在周池额外复制一份条目（子任务的「家」是主任务卡片，与任务级「今日⊂周」不同）；只有显式拖到周池的子任务才在周池显示条目，且该条目再进今日时会标注 `→ 今日` 箭头

## 🔄 多设备同步（可选）

不破坏「双击即用」：同步是可选叠加层，本地 localStorage 始终是工作副本，断网/离线照常使用，联网后自动补推。数据存放于你自己 GitHub 账号下的 **Secret Gist**（不公开、URL 不可猜测，且自带历史版本记录）。

**首次配置（每台设备一次，约 2 分钟）：**

1. 生成令牌：GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token，Account permissions 里只勾选 **Gists: Read and write**（不给仓库等其他任何权限）。[直达链接](https://github.com/settings/personal-access-types/new)
2. 在第一台设备（如 PC）打开页面 → 顶栏「**同步**」→ 粘贴令牌 →「**连接云端**」：自动创建数据 Gist 并上传本机数据
3. 在第二台设备（手机发送/接收同一 `index.html` 文件，用浏览器打开）→ 同样粘贴令牌 →「连接云端」：自动发现已有云端数据并拉取下来

**日常使用：**

- 打开页面自动拉取云端最新；每次改动后约 2.5 秒自动推送（可在同步设置里关闭自动推送，改用手动）
- 两端同时改动（极少见）时推送前会弹出选择：采用云端版本 / 用本机覆盖云端
- 同步设置里还有「立即同步 / 用云端覆盖本地 / 用本地覆盖云端 / 解绑」
- 顶栏「同步」按钮旁的小字显示上次同步时间；失败（令牌过期、限流、离线）会显示原因，本地数据不受影响

**安全说明：** 令牌只保存在各设备自己的浏览器 localStorage 中，**不会**随数据上传；云端只存任务数据 JSON，不含令牌。随时可在 GitHub 上撤销令牌或删除该 Gist。

## 💾 数据说明

- 数据保存在**当前浏览器 + 当前文件位置**的 localStorage 中：只要用同一个浏览器打开同一个位置的文件，数据就一直在
- 换浏览器、换电脑或移动文件位置后数据不会自动跟随——配置「多设备同步」自动对齐，或使用顶栏 **导出**（下载 JSON 备份）和 **导入**（选择备份文件恢复）
- 建议养成定期导出备份的习惯；「清空」操作不可恢复，操作前请先导出

## ❓ 常见问题

- **数据存在哪里？** 默认存在浏览器为该文件分配的 localStorage 中，纯本机；配置「多设备同步」后，云端副本在你自己的 GitHub Secret Gist 里。
- **为什么换了浏览器 / 电脑看不到我的任务？** localStorage 不跨浏览器、不跨设备。配置多设备同步自动对齐，或用「导出 → 导入」迁移数据。
- **同步会不会泄露我的任务数据？** Secret Gist 不公开、URL 不可猜测，令牌只授予 Gist 读写权限且只存在本机浏览器；云端数据不含令牌，随时可在 GitHub 撤销。
- **每次打开只有今日一栏？** 这是设计行为：专注今日；点开上面两栏即可查看全部，拖拽悬停也会自动展开。
- **每日重复任务什么时候刷新？** 零点结算时（页面开着会自动结算并提示；关着则下次打开页面时结算）：完成状态重置、任务回到今日列表。若当天把它从今日拖回周池，它就不会再自动回来，需要时再手动拖入。
- **误点了清空怎么办？** 如有最近的导出备份，导入即可恢复；否则无法找回，请务必先导出再清空。
