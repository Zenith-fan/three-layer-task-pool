# 三层任务池 · Three-Layer Task Pool

一个**纯本地、单文件**的三层任务池计划工具。无需安装、无需服务器、无需联网，双击 `index.html` 即可使用，所有数据保存在本机浏览器中，不上传任何网络。

界面为原子笔记风格的极简设计：战略总池（灰）→ 本周聚焦（琥珀）→ 今日动态（红），三层自上而下逐级聚焦。

## ✨ 功能特性

- **三层任务池**
  - **战略任务总池**（Strategic Backlog）：所有中长期任务与嵌套子任务的仓库；任务只有在周池中被完成后，才会在这里显示为已完成
  - **本周聚焦池**（This Week's Focus Pool）：本周要推进的任务；被选入今日列表的任务会标注 `→ 今日` 箭头（表示已出库，但在周池中保留）；今日任务完成或退回后箭头消失
  - **今日动态列表**（Today's Dynamic List）：今天要执行的任务；完成后自动归档回周池并计入「今日已完成」，未完成的任务次日自动顺延
- **自由拖拽**：按住任务左侧的 `⠿` 手柄，可在任意两个池之间移动，也可在池内排序（桌面与手机触屏均支持）
- **任务管理**：标题、简短备注、嵌套子任务；支持新增 / 编辑 / 删除 / 勾选完成，子任务可直接在卡片上勾选或快速追加
- **数据本地持久化**：自动保存在浏览器 localStorage 中，关闭页面后数据不丢失；支持一键导出 / 导入 JSON 备份
- **移动端适配**：手机浏览器打开自动切换为单列布局，操作方式完全一致
- **零依赖**：整个项目只有一个 HTML 文件，不引用任何外部库、字体或网络资源，完全离线可用

## 🚀 如何运行

**双击项目目录下的 `index.html`**，用浏览器（推荐 Chrome / Edge）打开即可，无需任何安装步骤。

> 小技巧：可以把 `index.html` 固定到浏览器书签或桌面，下次一键打开。

**在手机上使用**（任选其一）：

1. 把 `index.html` 通过微信 / 网盘 / 数据线发送到手机，用手机浏览器打开该文件；
2. 或者临时在电脑上起一个本地服务，手机同一局域网访问（可选，非必需）：
   ```bash
   # 电脑上进入项目目录后执行（需已安装 Python）
   python -m http.server 8000
   # 手机浏览器访问 http://电脑IP:8000
   ```

## 📖 使用说明

| 操作 | 方式 |
| --- | --- |
| 新增任务 | 每个池顶部的输入框输入标题，按 **回车** 保存 |
| 编辑任务 | 点击任务卡片（或卡片右侧 ✎），在弹窗中修改标题、备注、子任务 |
| 删除任务 | 卡片右侧 ✕（有二次确认），或编辑弹窗中的「删除任务」 |
| 跨池移动 | 按住卡片左侧 **⠿ 手柄** 拖拽到目标池；目标池会高亮并显示插入位置 |
| 池内排序 | 同样拖拽手柄，在同一个池内上下调整顺序 |
| 完成任务 | 在**周池**或**今日**列表中点击方框勾选；总池中的勾选状态为只读展示 |
| 子任务 | 点开卡片上的「▸ 子任务 n/n」直接勾选，末行输入框回车快速追加 |
| 搜索 / 过滤 | 总池顶部支持按标题、备注、子任务搜索，以及隐藏已完成 |
| 归档 | 周池中出现「归档已完成」按钮时，点击可把已完成任务收回总池 |

**箭头状态说明**

- 周池中任务带 `→ 今日`：该任务已进入今日列表（出库但保留在周池）
- 今日任务被**完成** → 自动归档回周池，箭头消失，总池中该任务显示已完成
- 今日任务被**拖回周池**（未完成返回）→ 箭头消失，任务留在周池继续推进

## 💾 数据说明

- 数据保存在**当前浏览器 + 当前文件位置**的 localStorage 中：只要用同一个浏览器打开同一个位置的文件，数据就一直在
- 换浏览器、换电脑或移动文件位置后数据不会自动跟随，请使用顶栏 **导出**（下载 JSON 备份）和 **导入**（选择备份文件恢复）
- 建议养成定期导出备份的习惯；「清空」操作不可恢复，操作前请先导出

## ❓ 常见问题

- **数据存在哪里？** 存在浏览器为该文件分配的 localStorage 中，纯本机，无任何网络上传。
- **为什么换了浏览器 / 电脑看不到我的任务？** localStorage 不跨浏览器、不跨设备。用「导出 → 导入」迁移数据。
- **误点了清空怎么办？** 如有最近的导出备份，导入即可恢复；否则无法找回，请务必先导出再清空。
